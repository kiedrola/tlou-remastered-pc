**The Last of Us Remastered: PC port** 0.4.0

PC settings, the save list and a Quit to Desktop button inside the game's own menus, much less
system memory and a faster start with fewer hitches, mouse aiming in the sniper scene and with
scopes, steering pushed dumpsters and pallets with the mouse, and support for more controllers.

> **No game files are included.** You need your own decrypted copy of the game and its update. This
> project is not affiliated with Sony Interactive Entertainment or Naughty Dog.

**Discord:** help, testing and news: https://discord.gg/9mnjjezcNj

## Fixes and improvements

- **PC SETTINGS in the game's Options**: the main menu's and the pause menu's **Options** have a new
  **PC SETTINGS** page, drawn with the game's own menu widgets and translated into all of its
  languages: display mode, VSync, frame rate limit, anti-aliasing, sharpening, the performance
  overlay, mouse sensitivity, aim and scope sensitivity, mouse up/down speed and invert, and
  controller vibration. Changes apply at once and are saved. **MORE PC SETTINGS...** opens the
  overlay menu with everything else.
- **The save list in the game's own menu**: **Load Game** and **Save Game** now open a page like the
  game's Chapters page instead of the overlay list. Each save shows its chapter's picture (also from
  the pause menu), where it was made ("Area - Sub-chapter", in the game's language) and its date;
  **New save** is the first row. Deleting saves still uses the overlay list.
- **Quit to Desktop** ([#192](https://github.com/ravencaio/tlou-remastered-pc/issues/192),
  [#199](https://github.com/ravencaio/tlou-remastered-pc/pull/199)): a **QUIT TO DESKTOP** button in
  the main menu and the pause menu, in every game language. From the pause menu it asks first, on
  the game's own Yes/No page.
- **Much less system memory, a faster start and fewer hitches**: at start the game prepared every
  shader it had ever cached (about 13,700) while a session uses about 520. It now prepares the
  1,000 used most recently and loads the others when they are first needed. On a GTX 1050 Ti with
  16 GB: system memory in use went from 23-25 GB to about 6 GB, the background shader warm-up from
  about 50 s to about 4 s, gameplay from 44-48 to 52-53 FPS, and the biggest hitches from about
  0.4 s to about 0.15-0.2 s.
  - The thread that sends the GPU its work waits less for fences: a little more headroom on busy
    scenes (about 0.5 FPS on the same card).
  - Each of the recent optimizations can be turned off in the launcher's **Debug** tab
    (**At start** > **Recent optimizations**), to compare if something looks wrong.
- **Mouse**:
  - **Sniper scene** ([#168](https://github.com/ravencaio/tlou-remastered-pc/issues/168)): at the
    end of Pittsburgh the scope aimed like the old emulated stick, and a diagonal mouse movement
    moved it along one axis only. The mouse now aims it directly.
  - **Scopes** ([#168](https://github.com/ravencaio/tlou-remastered-pc/issues/168)): scoped aiming
    turned much faster than normal aiming. The mouse now slows down with the scope's zoom, and a
    new **Scope sensitivity** (launcher **Controls** > **Mouse**, the overlay menu and **PC
    SETTINGS**) adjusts it from 10% to 200%.
  - **Sensitivity ranges**: mouse sensitivity and aim sensitivity now both go from 10% to 500%.
  - **Pushing dumpsters and pallets** ([#185](https://github.com/ravencaio/tlou-remastered-pc/issues/185)):
    the object turned only a little with each mouse swipe. The mouse now turns it about four times
    faster.
- **More controllers**: generic USB gamepads and console-pad adapters that only work as DirectInput
  devices now drive the game. The launcher's **Controls** window chooses the mode and lets you
  remap their buttons by pressing them.
- **Flashlight** ([#132](https://github.com/ravencaio/tlou-remastered-pc/issues/132)): the port
  keeps the flashlight from flickering, as before; **Flashlight never flickers** in the launcher's
  **Controls** window (Controller tab) can now turn that off for the game's original behavior. Then
  shaking a controller with motion sensors (DualShock 4, DualSense and others) fixes the
  flashlight, as on the PS4, and a key or button can also be bound to the shake.
- **Resolutions**: the launcher's **Resolution** list goes from 640x360 to 4K-sized resolutions in
  16:9, 16:10, 21:9 and 32:9, each shown with its aspect ratio.
- **Overlay menu shortcut** ([#170](https://github.com/ravencaio/tlou-remastered-pc/issues/170)):
  the in-game overlay menu now opens only with the keyboard key (**Insert**) unless you choose a
  controller shortcut; LT + R3 is no longer on by default.
- **RivaTuner overlay** ([#48](https://github.com/ravencaio/tlou-remastered-pc/issues/48)): the
  RivaTuner Statistics Server on-screen display (used by MSI Afterburner) flickered, missing from
  some frames. When RivaTuner is running the game now presents its frames in a way the overlay
  shows on every frame.
- **Anti-aliasing** is now off by default (it was FSR 3); choose it in the launcher or in **PC
  SETTINGS**.
- **Freezes** ([#158](https://github.com/ravencaio/tlou-remastered-pc/issues/158),
  [#190](https://github.com/ravencaio/tlou-remastered-pc/issues/190)): when the game stops drawing
  frames for 10 seconds (for example stuck on "Loading Shader Cache"), the log now records where
  each thread is. If it happens to you, please attach the log.

## Update

**From 0.1.8 or newer:** use the launcher's **Update** button. **From 0.1.7 or older:** extract the
zip over your previous folder. Your saves, settings and logs are in its `analysis` folder.

## New install

1. Download **TLOU-Remastered-windows.zip** below and extract it to a folder with plenty of free space.
2. Open **TLOU Launcher.exe**.
3. Click **Folders** and choose **Game files**: the folder with `eboot.bin`. Update 1.11 is looked
   for beside it, in the folder of the same name ending in `-patch`.
4. Click **Play**. You can also open **TLOU Game.exe** to start with your saved launcher settings.

Intel integrated graphics (6th generation and newer) need Intel's own current driver for Vulkan
1.3; a laptop maker's older driver can stop at Vulkan 1.2.

## Known issues

- Intel integrated graphics are slow (about 10 FPS at 1080p on a UHD 630).
- Stripes on some walls on RTX cards ([#58](https://github.com/ravencaio/tlou-remastered-pc/issues/58)).
- Volumetric light can look a little odd right at the edges of objects in front of it
  ([#55](https://github.com/ravencaio/tlou-remastered-pc/issues/55)).
- A thin light ring can remain where wheels and feet touch the ground: the game's own design,
  made thinner by **Contact shadows at half resolution**.
- Short pauses can occur the first time an area is played while its shaders compile.
- DLSS and FSR 4 are not in this package: DLSS falls back to FSR 3.
- Dubs from other regions have not been tried with files from a European or Japanese copy yet.
- Online play (Factions) is not available.

When reporting a problem, attach `analysis\tlou\boot.log` (**Open log** in the launcher), or ask
on the Discord server.
